# docs/evidence

Per-order directories: decisions.md (structured decisions with evidence, rejected options and reopening conditions), handoff.md (one line per acceptance criterion at implementation-ready), README.md (the order's evidence account) and fixture transcripts. `target-records` moves a target order's decisions into the target's docs/dotln/, and what stays here is the raw evidence. current.json selects evidence editions once this instance records any.
