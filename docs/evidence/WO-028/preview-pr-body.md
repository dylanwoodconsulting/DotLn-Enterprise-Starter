AI for Games gains twenty more checked concept studies, bringing it to forty and the catalog to eighty. They cover the next Movement concepts, among them Flee, Collision avoidance, Obstacle and wall avoidance, Corner trap, Projectile trajectory and The firing solution. Each runs a tested TypeScript model, drawn by the existing `motion` and `timeline` families. No page, route, family or runtime dependency is added.

Two shared changes come with the batch. The `motion` drawing now places names apart from the physical points, keeping each above its anchor when there is room and otherwise using the nearest clear row or gap, with a thin guide back to the unchanged point. A study's Chart view now has its own legend and guide, and Follow the mechanism shows the executable model and spec paths.

Verification walked the operator's session in the served production build at 360, 768, 1440, 2080 and 3840 pixels. It measured every drawing's labels on every frame of all forty AI for Games studies at those sizes: none is clipped or overprinted. The registered target review gate passes all eight commands, and the Tools, tooling and browser suites pass uncached.

Some small defects are boarded rather than fixed, none of them breaking an acceptance criterion. The most visible is that Obstacle and wall avoidance's default run shows the ray acting for only 0.2 s, so most of the visible turn comes from the pull towards the delivery point.
