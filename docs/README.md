# docs

The document roots of this launchpad, at the default layout (`dotln.config.json`
at the repository root moves no root). Each root's README states its convention;
`UPSTREAM.md` at the repository root names the kit's commit and the upstream
documents the kit points to, and [PLAYBOOK.md](PLAYBOOK.md) is the kit's operating
playbook.

- [`docs/launchpad-readme.md`](launchpad-readme.md) — the launchpad's own README, kept off the main page while the starter's updates rewrite the root one
- [`docs/operator/`](operator/README.md) — the operator record every session reads, and the reusable guidance it links
- [`docs/control/`](control/README.md) — control records, the generated current page and this instance's settings
- [`docs/evidence/`](evidence/README.md) — per-order decisions, handoffs and evidence
- [`docs/verifications/`](verifications/README.md) — immutable verifier reports
- [`docs/final-reviews/`](final-reviews/README.md) — immutable final-review reports with their PR and release-notes handoffs
- [`docs/planning/`](planning/README.md) — dated planning passes, the proposed sequence and the follow-up register
- [`docs/publication/`](publication/README.md) — the implementation overlay template and any compiled publication
- [`docs/product/`](product/README.md) — the kit's two product documents and this instance's overlay
- [`docs/discovery/`](discovery/README.md) — the environment truth
- [`docs/decisions/`](decisions/README.md) — architecture decision records
- [`docs/releases/`](releases/README.md) — the release tag manifest template
- [`docs/observations/`](observations/README.md) — observation logs
- [`docs/work-orders/`](work-orders/README.md) — one scope authority per order, `WO-NNN-<slug>.md`, with **Model:** and **Effort:** as its leading metadata; its README is the index `npm run work-orders -- index` generates
- [`docs/lineage/`](lineage/README.md) — idea-ledger.md, an append-only idea history; its README is generated by `node scripts/lineage.mjs index`
- `docs/intake/` — ignored, single-copy raw material in the main checkout; a worktree's captures reach it at release close
- [`docs/workstreams/`](workstreams/README.md) — one document per outcome; the README holds the convention and template
- [`docs/repositories/`](repositories/README.md) — one profile per registered repository; the README holds the convention and template
