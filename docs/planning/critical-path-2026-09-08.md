## The critical path

The [purpose](../product/purpose.md) names a reference Angular workspace in
which a feature can be added by convention. Its foundation dependency path is
repository registration (WO-003), a witnessed scaffold (WO-004), shared
libraries (WO-005), the component taxonomy (WO-006), events and stores
(WO-007), the sub-app shell (WO-013), and a legitimate client-side
authentication and permission model (WO-008). All of those prerequisites
except WO-008 are closed. WO-008 remains the open foundation outcome; it does
not gate the catalog, scene or machinery examples that currently expose no
authenticated route.

This declaration describes dependencies. The [sequence](sequence.md) is the
maintained record of the operator's chosen delivery order.
The [2026-10-24 pass, D11](mining-run-orders-2026-10-24.md)
places the useful sandbox examples before authentication and authentication
before the twin. The [concept-batch pass](concept-batches-and-quality-passes-2026-10-30.md)
places the operator's study batches at the front as side work. Declaring the
foundation path changes neither choice and creates no activation authority.

Revisit the dependency reading if a feature introduces an authenticated or
permission-gated route earlier, a prerequisite changes, or the operator changes
the intended outcome. Revisit the schedule only under its recorded sequencing
conditions; the existence of this declaration alone supplies no new priority.
