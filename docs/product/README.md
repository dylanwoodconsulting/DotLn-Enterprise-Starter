# docs/product

The kit carries the execution guide (07-execution-guide.md) and the publication compiler (08-publication-compiler.md, which the reviewer skill cites) whole. This instance's product overlay lives here as instance files: [purpose.md](purpose.md), whose marked block the refutation goal standard reads, and [concept-study.md](concept-study.md), the direction for studying a concept in DotLn-Angular's catalog. Core's other product documents are upstream pointers in UPSTREAM.md.

`node scripts/docs-check.mjs` judges the two overlay documents against their ceilings in `docs/control/doc-ceilings.json`, which a planning pass sets. The purpose block is bound to the latest planning receipt, so a change to it belongs to a planning pass; `npm run plan -- check` refuses one made anywhere else.
