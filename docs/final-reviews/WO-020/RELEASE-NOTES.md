## Release overview

This minor release gives AI for Games its first twenty concept studies and the machinery every later batch of studies reuses. A reader opens Tools or the catalog, sees the work's twenty studied concepts counted on the shelf and marked in Chapter 3's contents, and under each of those concepts reads a study on one example: a drawing to step or play with its text equivalent, a chart, live inputs, pseudocode with the worked numbers, an RxJS reading where streams clarify the idea, public implementations, references with the claim each supports, the limits with a failure shown, and the nearby concepts. Readings now have addresses, so Back and a shared link return to them, and the Tools home opens without loading a work.

## Read before upgrading

- **Readings open from the address.** A concept's reading is `/tools/catalog/` followed by its id, the route `catalog/:toolId`; `/tools/catalog` opens the shelf and no reading. The persisted reading state (`dotln-angular.tools`) no longer restores a selected concept and gains the newest reading's title; state stored by the previous release is read, its selected concept is simply not reopened, and a reading stored before titles were kept is linked from the home without a name until a catalog load supplies one.
- **The catalog loader contract grows.** `CatalogLoader` now has `study(id)` and `summary()` beside `load(work)`. A replacement loader must implement them; the bundled loader and the test kits do.
- **Catalog events change.** `relationFollowed` is removed in favour of `conceptOpened`, `readingClosed` and the summary events are added, and a `toolsHomeEvents` group arrives. Only the catalog store and the Tools feature consume these.
- **The study record is closed.** `concept-study-v0` is validated by `npm run studies:check`, which `check:fixtures` now runs; a change to the record's shape after this release is a new schema version. Three new npm scripts: `studies:check`, `studies:report` and `studies:links`; the last reaches the network and no gate runs it.
- **The scene engine's public API gains exports** (steering, blending, formation, slot assignment and vector functions) with no behaviour change. The hand-wired Arrive example and its translation keys are removed; the study translations are replaced wholesale under `tools.study`.
- No dependency is added or changed. Node 26 and npm as before.

## Substantive changes

- **The catalog reading surface.** Twenty studied concepts in AI for Games, each at its own address below the mined definition, with a Jump to the study line under the title beside the scene link; the studied marks in the contents and the search results; the `Study` facet; a list of the work's studied concepts when a work is chosen and nothing is open; a visible, retryable notice when the study counts fail to load while the concepts still read.
- **The study.** The record's sections in the order the comparisons chose: the authored mark, the idea and the situation, the example in full behind a disclosure, the drawing with its controls, the moment's note with the numbers behind a disclosure, Try another value, How to read this drawing, then Follow the mechanism, Think in streams, Where this breaks down and See it elsewhere behind native disclosures that defer their content, the nearby concepts and Next study. Play runs from the selected moment at the example's own pace and stops on any hand step, on leaving the reading and at the end; it is not offered under reduced motion, and turning the preference on stops a run.
- **The record, the check and the summary.** One JSON record per study, the closed schema, the check with its three negative fixtures and 66 tooling tests, the generated `studies-summary.json`, the coverage report and the link helper.
- **The families and the models.** The `motion` and `timeline` families with a shared scrubber and inputs block, pure drawing modules, and twenty model modules with specs that assert the numbers the prose shows, the behaviour each claims, the failure each comparison shows and the soundness of every live input across its range.
- **The Tools home.** Works, counts, studied counts and the last reading from the two summaries and the stored history, with its own facade, loading no work's chunk.
- **Documents.** The catalog architecture gains §Studies; the catalog rules carry the study rules; the scripts reference names the new check and helpers; the sub-app table and the library READMEs name the reading route and the studies.

## Progressive polish

Chart labels no longer clip at the left edge, the drawing area having widened without moving the base's geometry. Drawings name bodies and marks and drop a name that would collide; vectors carry heads; the chart switch reads Movement and Chart with the chart's own title above it; labels inside a drawing use the interface's type. Three study visual baselines are added and the three catalog baselines updated for the changed Arrive reading. The Tools feature's test kits gain a home facade kit and a bundled-study loader for model specs.
