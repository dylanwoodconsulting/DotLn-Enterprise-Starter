# Add twenty enterprise application pattern studies, each read against the app's own code

Patterns of Enterprise Application Architecture gains twenty studied concepts in the catalog, the twenty most related rows of the work. Sixteen run a small in-memory TypeScript model of the mechanism, which a new `states` drawing steps as a register of the example's objects and their states, and four structural choices are described without a drawing. Every study names first the file in this app where the pattern or a cousin of it lives, as its author's reading of the code, so a reader can see which patterns the stores and data access already carry, under what name, and where each one stops. The same change removes the catalog loader's `tool-v0` compatibility reader, whose one promised release ended long ago.

## What changed

The three commits can be read one at a time: the reader's removal, the batch as independently verified, and the final review's corrections to its text.

- **The `states` family.** `composites/study-visuals/states/` draws the register: states across as columns, objects down as rows, each token in the column of its state. A token that moves at the selected step is green, with an arrow from the column it left and the operation above it; the column it enters is tinted, and an object that leaves the example leaves a dashed ring. The text equivalent names what moved and where every object stands. Under reduced motion a token is simply there, and nothing plays by itself; below 600 pixels the register is drawn for a phone's width. `studies/states.ts` builds a study from a simulation's language-free snapshots and the presentation's words, derives each step's moves from the snapshot before it, and refuses a state, object or transition the example lacks, so the drawing and the model's spec read the same run. The register stands alone for now: its comparison with a state-machine drawing of the same model waits for a dedicated A/B pass, and the machine's source is kept outside this repository for it.
- **The twenty studies.** `libs/shared/catalog/src/studies/poeaa/` holds the records, loaded as one lazy chunk; their text is in `apps/dotln/public/i18n/studyPoeaa/en.json`. The sixteen running models live under `libs/features/tools/src/lib/studies/poeaa/`, each an entry composing a simulation and a presentation, with a spec that drives the study's own example. Domain Model, Transaction Script, Template View and Page Controller carry no model and no drawing, because each is a choice of where logic or markup lives and a stepped drawing would show a call sequence as state.
- **Where the app embodies each pattern.** Each study's first implementation is pinned to this repository at `9637f73` and begins as the author's reading of the code: where the pattern or its cousin shows and where it stops, then two or more public implementations. `docs/dev-reference/architecture/events-and-state.md` gains a section naming the patterns the stores and data access carry, linked to their studies.
- **Rules and checks.** `check-studies.mjs` requires a states drawing of a model that runs to read that model's module, and holds the enterprise work's RxJS readings to the illustrative mark; tooling tests pin the batch's twenty ids, its four structural records and its sixteen running models. The corpus test checks every states token is one character, and that headings and operation names stay inside the drawing at every input boundary in both layouts. `catalog.md`, `catalog-rules.md` and the test kit's README describe the family, the models and the embodiment rule.
- **The `tool-v0` reader.** `catalog-loader.ts` reads `tool-v1` only, and its spec now asserts that a `tool-v0` chunk is refused; the conventions, `catalog.md` and `catalog-rules.md` stop promising the reader.
- **The final review's corrections.** Sixteen sentences in seven studies contradicted their own run at an input inside its range, or the app's code. Unit of Work said a save never removes a composition, though a save drops a stored one that could not be read; its first limit and Pessimistic Offline Lock's assumed an input their claim needs; Service Stub's text assumed the stub that reads the scenario, Lazy Load's one chunk per work; Gateway and Service Stub disagreed about where the stub stands; Unit of Work's description and Identity Map's comparison misread at some counts; and Remote Facade counted the rows of a failed source and called the board's data access the app's only network fetch. Each now holds at every declared input. A Data Mapper comment and the catalog's account of the narrow register's headings and of the study check were corrected too.

## Validation

- The registered review gate (install, lint, type check, unit tests, format, build, browser and visual tests) passed on the reviewed tree with no tracked-byte change. The second commit's tree is the one an independent verification passed, and the review gate passed there as well.
- An independent verification stepped the reading session the change was planned for in a production build at 360, 768, 1440, 2080 by 1460 and 3840 by 1620, with no horizontal overflow and no console error, and probed the sixteen models over 84 input combinations and 593 frames, including atomic rollback, shared identity and partial versus failed remote replies.
- Two critics reviewed all twenty studies before they were marked checked. All 75 addresses the studies cite answered 200 on 2026-11-07, and every first implementation names a file that exists at `9637f73`.
- After the corrections, the study check reports 100 records and 0 problems, the message check finds no missing key, the tooling tests pass 94 of 94, and the eight corrected models' specs, the corpus test and the family's specs pass 77 of 77.
- The initial bundle is 406,523 bytes with no lazy code in it; the records' chunk is 74,526 bytes. `package.json` and the lockfile are unchanged.

## Limits and follow-ups

None of these blocks the change.

- On a phone, a state's name too wide for its column is drawn smaller, down to about 6.5 pixels for Service Layer's "Announced". Whether such a name should break, abbreviate or keep a floor size waits for the A/B pass or the next standards pass over the drawing families, with a test that the template applies the column's scale and a guard for an empty label.
- Tokens show one letter or digit, as the flow and marble drawings do, rather than translated text.
- Fifteen of the sixteen presentations keep switch-based name lookups and their own list joining, and Foreign Key Mapping's read limit counts reads rather than keys still to resolve, which no input reaches today; the next standards pass over the batch takes them.
- Browser checks ran in Chromium only.
