## Release overview

`Launchpad v0.3.5` is a documents release that brings this launchpad's planning layout to the kit's contract, as core's is. A planner opening `docs/planning/` sees the four inputs they use (the sequence, the follow-up register, the cost table and a planning page that says what each is for) and the three directories that hold the records (`passes/`, `refutations/`, `entropy-reviews/`); the nineteen dated planning documents that stood beside them moved under `passes/` by rename, with their bytes intact. A reader following an old link from any record still arrives, because a move map resolves the old paths inside the kit's readers and no record was rewritten. The features page now says the operator chose to keep desktop control off and why, and a status read prints the state without warning about its own projection. The release is for the operator and for the planning sessions that open this directory at the start of their work. It is a patch release: no kit file, runtime, dependency or other registration key changes. The kit is starter v0.117.0, taken by #58. Since `v0.3.4` the interval also merged five starter updates (v0.105.0, v0.112.0, v0.113.0, v0.115.0 and v0.117.0), six planning passes and the review records of five DotLn-Angular orders (WO-026, WO-020, WO-021, WO-022 and WO-028), each under its own pull request.
