## Release overview

This minor release gives the RxJS work its first twenty concept studies, each built on an example that really runs. A reader opens Tools or the catalog, sees RxJS counted as twenty studied, and under switchMap, shareReplay, BehaviorSubject and seventeen others reads one worked example from several sides: the idea and a situation it serves, a marble diagram stepped frame by frame or played on command, ordinary pseudocode, the code itself, public uses, references, limits and the nearby operators. It matters because the drawing is not an illustration: the module that draws it is the module a test ran, so what each operator keeps and silently drops can be read from the diagram and trusted.

## Read before upgrading

- **The study model is discriminated by family.** `StudyModel` is now a union of `MotionStudyModel` and `MarblesStudyModel`, and `StudyDrawingView` a union of the matching views. Code that read `model.motion` directly narrows on `family` first, and moments are read through `ticksOf`. `StudyFrame` is now `MotionFrame`, and every movement model returns `family: 'motion'`. These are internal to the Tools feature.
- **The record check is stricter for RxJS.** `npm run studies:check` now refuses an executable RxJS reading whose shown code is not in its module, whose spec does not call `expectMarbleExample`, or whose marble drawing reads another module. In the RxJS work a reading must run or begin with `// Illustrative:` and its reason. The AI for Games records are unaffected.
- **A file named to `check-studies` that does not parse** now reports `FAIL check-studies` with exit 1, rather than a raw JSON error.
- **`StudyScrubber` takes `frame` as well as `seconds`.** `seconds` is optional, and a marble diagram's slider reads Frame 5 of 14. `tools.study.frameOf`, `tools.study.emissions` and `tools.study.rxjs.spec` are new translation keys.
- **`rxjs/testing` reaches production.** The marble builder uses the TestScheduler's parser at run time, in a lazy chunk of 14.5 kB that loads with the first marble study. It is part of the RxJS the app already carries.
- **`.gitignore` gains `/.runtime/`.** A local tool's temporary root no longer shows as untracked.
- No dependency is added or changed. Node 26 and npm as before. A branch that publishes after this one integrates `main` and rewrites `studies-summary.json` with `npm run studies:check -- --write-summary`.

## Substantive changes

- **The catalog reading surface.** Twenty studied concepts in RxJS, each at its own address: switchMap, concatMap, mergeMap, exhaustMap, scan, combineLatest, startWith, share, shareReplay, Subject, BehaviorSubject, ReplaySubject, catchError, retry, repeat, timeout, finalize, takeUntil, materialize and observeOn. The shelf, the home, the studied list and the `Study` facet count them with the movement twenty, forty in all.
- **Marble diagrams.** The new `marbles` family draws input streams and the streams an operator opens above its band, outputs below, with every frame numbered and every frame a step. A cut-off lane ends in a small hollow ring, a cross is an error, and what nothing received is not drawn. A diagram opens on its last frame, the whole run; an output lane shows only what has been emitted by the selected frame, so stepping back or pressing Play watches each value ride down from the emission it comes from. Under a reduced-motion preference nothing glides or animates and Play is not offered; stepping stays. The text equivalent names each frame's emissions behind Show the emissions.
- **Executable examples.** Each study's module exports its marble strings and its pipeline, a spec runs them under the TestScheduler through `expectMarbleExample`, and the drawing reads the same module. The study labels its code executable and names the spec that ran it. All twenty are executable, including observeOn and materialize, which the rule allowed to be illustrative.
- **Comparing operators.** share and shareReplay run the same streams and differ at frame 7, concatMap and mergeMap share one upload example, and Subject, BehaviorSubject and ReplaySubject read as three memories. Each study's limits say what the operator silently drops and which nearby operator to reach for.
- **The study model and its check.** The model carries a family and the shared moments every family reads, so the next family without motion frames needs no change to playback or the mapper. The record check holds the shown code to the module that runs it.
- **Documents.** The catalog architecture gains the family, the stream study's module and the coverage table; the catalog rules state the executable rule; the README's menu table names the reading route.

## Progressive polish

The worked step's rounding note is left out of marble studies. Every marble study's caption ends with how the drawing opens and fills in. The disclosure under a marble diagram is called Show the emissions, while movement studies keep Show the numbers. An unused computed left the explanation component. Three visual baselines are added for the marble study at 360, 768 and 1440. The study fixtures and stories gain a marble case, and the fixtures' text equivalents now come from the model.
