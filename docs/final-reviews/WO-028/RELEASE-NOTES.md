## Release overview

This minor release doubles the studied Movement concepts of AI for Games and moves every study's text into the message system. A reader opens Tools or the catalog, sees AI for Games counted as forty studied, and under Flee, Collision avoidance, Obstacle and wall avoidance, Projectile trajectory, The firing solution and fifteen others reads one worked example from several sides: the idea and a situation it serves, a drawing stepped moment by moment with a sentence for each, a chart, ordinary pseudocode, an executable model with its spec, public implementations, the book, the limits and the nearby concepts. It matters to a reader because the steering ideas the soldier scene's rail still lacks, and where each fails, can now be read and stepped. It matters to a contributor because all eighty studies, old and new, now keep their prose in lazily loaded message catalogs and their mechanisms apart from their presentation, with checks that refuse the next study that does otherwise.

## Read before upgrading

- **The study record is `concept-study-v1`.** Every authored text field of a record holds a message key, and the English lives in `apps/dotln/public/i18n/studyAifg/en.json`, `studyRxjs/en.json` and `studyEip/en.json`, with shared drawing narration in `studyCommon/en.json`. Ids, addresses, dates, module paths and example parameters keep their meaning. The loader refuses a chunk that is not v1. `concept-study-v0.schema.json` stays in the repository unchanged.
- **A model takes a translator.** `StudyModelFunction` is `(parameters, t) => StudyModel`. Every model module, spec and drawing builder passes one; specs use `studyTranslate` from the Tools testing entry point, which reads a copy of the served catalogs that `tools/i18n-copies.test.mjs` holds equal to them.
- **`MessageCatalog` loads feature messages.** The i18n library exports `MessageCatalog`, `provideMessageCatalog` and the `TranslateMessage` type, with `provideMessageCatalogTestKit` in its testing entry point. The Tools route provides it. `TranslocoHttpLoader` now accepts `scope/language` and loads that scope's catalog from its own folder under `i18n/`, such as `i18n/studyAifg/en.json`, refusing an unsafe scope or an unconfigured language.
- **The catalogs are assets the build must ship.** A reading fetches `studyCommon` and its work's catalog on first open. A catalog that answers but lacks a study's keys shows raw keys rather than the failure state, so the JSON files and the JavaScript must be deployed together.
- **Movement models are three files.** For each study a `.simulation.ts` file owns the mechanism, a `.presentation.ts` file the frames and explanations, and the `.model.ts` file composes them and re-exports the simulation's functions. An import of a mechanism from the model module still resolves.
- **A marble event's `from` is a stream id.** It was the lane's label. The marble builder rejects duplicate ids across input, inner and output lanes.
- **Three checks are stricter.** `npm run i18n:check` refuses a missing study message and literal presentation text in a model source. ESLint refuses a function over 80 nonblank, noncomment lines under `src/lib/studies`. `npm run studies:check` requires v1 records whose every key resolves.
- **Forty-eight stream narration messages changed wording.** A computed count is now a numeric parameter, so a sentence that read a number as a word now shows a digit. Meaning, timing and values are unchanged.
- **The Tools tests have a 20-second timeout**, set in the project's Vitest configuration.
- No dependency is added or changed. Node 26 and npm as before. A branch that publishes after this one integrates `main` and rewrites `studies-summary.json` with `npm run studies:check -- --write-summary`.

## Substantive changes

- **The catalog reading surface.** Twenty more studied concepts in AI for Games, each at its own address: Steering behaviors, Projectile trajectory, Variable matching, Jump points, Motor control, Movement in the third dimension, Flee, Collision avoidance, Obstacle and wall avoidance, Corner trap, Blending versus arbitration, Actuator, The firing solution, Iterative targeting, Coordinated movement, Two-and-a-half dimensions, Steering output, Kinematic arrive, Satisfaction radius and Kinematic wander. The shelf, the home, the studied list and the `Study` facet count forty for the work and eighty in all.
- **Executable models.** All twenty run. Twelve call the scene engine for the behaviour they teach and integrate it locally; eight are local, such as the projectile solver and the kinematic rules. Each record says which, and each spec drives the model through the record's example. A TypeScript study now shows its model and spec paths under Follow the mechanism.
- **Readable drawings.** The `motion` family places names independently of their physical points, with a guide back to the unchanged point, and renders names above vectors. The chart view keys its legend to the chart's own series.
- **Study text in the message system.** Record prose, model narration, labels, worked arithmetic, comparisons and legends are messages with named values. A study's catalog loads with its first reading and stays loaded for the work; the shelf and board load none.
- **Mechanism apart from presentation.** A simulation never sees a translator, and retains each step's calculation so every displayed number is the one that advanced the run. Stream studies keep raw payloads and describe them separately.
- **Guards and guidance.** The checks above run in the gate, and the catalog rules, architecture and conventions state the rule that a record field is not a translation exemption and that the size cap is a ceiling, not a design target.

## Progressive polish

Symbols, axis ticks and module paths in the drawings pass through house message templates. The study composite's legend tracks by position, since a chart may repeat a tone. The lint rule for study function size matches from a project's own configuration as well as from the workspace root. Formation pattern interface names its escorts through their display messages in a readout no prose yet reads. The catalog and Tools test kits and the study fixtures moved to the v1 record. The catalog's visual baselines at 768 and 1440 show the new studied counts.
