## Release overview

The twenty enterprise application pattern studies now have code a colleague can read top to bottom and copy into the next executable-model batch. Each of the sixteen running presentations reads a state's or an object's display name and its token letter from one table keyed by the study's own ids, which the compiler holds complete, chooses by an operation's kind through a table of one function per kind, joins every list through the shared helper and reads an on/off input as a boolean. The states builder infers a move's transition where exactly one joins its states and refuses an ambiguous move, the tools test kit has one loader for a study a model draws, and a chart names its x values for what they hold. Nothing on screen changes except at a phone's width, where a state heading too wide for its column now keeps two thirds of its size and breaks a longer name across two lines instead of shrinking to about six pixels, and Foreign Key Mapping's read limit now stops only before a key that needs a read.

## Read before upgrading

Nothing needs doing: no route, dependency, configuration, stored record, message or public interface changes, every model's run is unchanged at every declared input, and the visual baselines are the same. Two things read differently. At 360 pixels the state headings of Service Layer, Data Transfer Object and Record Set that were drawn at six to eight pixels are drawn at nine pixels or more, with Accepted, Announced, Refused, Encoded and Unchanged broken across two lines with a hyphen. A spec that read a flow or states study through the test kit's `loadFlowStudy` or `loadStatesStudy` now calls `loadModelStudy(id, family)`, and one that read a token letter from the register drawing reads it through `tokensOf`.

## Substantive changes

**Lookups as tables.** A display name, a token letter and a state's or a part's name come from a `Record` keyed by the study's id union and checked with `satisfies`, so a missing or an extra entry fails to compile and no `default` branch stands for a case that cannot occur; the sixty-nine `switch` statements the sixteen presentations held are gone. A choice by an operation's kind goes through `matchKind`, a table of one function per kind, each given the value of its own kind. Every list joins through `listOf`, an on/off input is a boolean read by `booleanParameter`, a comparison's two runs travel in the run description the entry module builds, Gateway's success rule is one function Service Stub imports, and Record Set's positional transition helper goes.

**The states builder.** A move between two states that exactly one transition joins takes that transition without being named, a move no transition joins takes none, and a move two transitions could have taken is refused when the example builds, naming the object, the states and the transitions. A snapshot names a transition only where two join the same states or an object takes a transition back into its own state, so each presentation's naming shrinks to those cases. The builder drops a null placement or note, and the move sentence joins names through the shared helper.

**Foreign Key Mapping's read limit.** The loader stops on its read limit only when the next key still to resolve needs a read: every key without an identity map, and through one only a key whose row has no object yet. With a limit of three the identity-map run now finishes all six references on three reads, where it stopped short before; the study's example keeps its limit of six and its run frame for frame. A spec pins every limit from one to six, and the same test fails on a copy carrying the previous simulation.

**The narrow register's headings.** At a phone's width a state's name is drawn at the largest size at which its widest line fits its column, never below two thirds of the stylesheet's size; a word that would need less breaks across lines with a hyphen into the fewest parts that fit, the longer part first, and its lines take the size they then fit. Service Layer's smallest heading rises from 6.16 to 9.24 pixels, Data Transfer Object's from 7.92 to 9.24 and Record Set's from 7.97 to 8.97; the other thirteen registers and the wide register are unchanged, and Gateway's narrow note, measured with real glyphs, ends 10.07 drawing units short of the first state's column.

**Charts over steps and counts.** A chart's x values sit under the name of what they hold, `seconds`, `steps` or `counts`, so a comparison over the steps of a run cannot pass for one over a movement example's clock, and the timeline drawing reads them whatever their name. Foreign Key Mapping, Identity Map, Remote Facade and Unit of Work chart steps, Lazy Load charts readings opened, and the forty movement charts are unchanged.

**One loader.** `loadModelStudy(id, family)` in the tools test kit reads a study the given family draws from a model module and refuses one another family or no model draws; the twenty messaging specs, the RxJS localization spec and the sixteen enterprise specs import it, and the model specs read the model's frames and `tokensOf` rather than the register drawing, whose geometry the family's own specs judge.

## Progressive polish

The states drawing rule moves out of the study check's RxJS checks into a function of its own, with the rule, its message and its tooling test unchanged. The token rule is written down: a drawing's token letters are symbols shown through the house symbol template with the translated name beside them, in all three drawing families, and are not translated. The catalog architecture document states the lookup-table shape, the inferred transition, the one loader, the chart axes and the narrow register's rule; the catalog rules name the shapes a presentation takes; the test kit's README names the one loader and `tokensOf`.

## Evidence and compatibility

Built on `v0.11.0` (`f99580f`) with no dependency, Node or Angular change. A production crawl of all 238 frames of the twenty enterprise studies at 1440 and 360 pixels finds the rendered text and accessible labels identical at the base and at this release outside the 25 narrow-register frames of the three studies whose headings changed, and within those frames only the six broken headings differ; a comparison of the sixteen running models over 174 default and declared-input cases finds every output identical; an independent verification repeated the crawl on its own build with the same result and replayed it against the reviewed tree with no difference. The comparator refuses a control with one unrelated text node changed, and the verification's four further controls. Foreign Key Mapping's read-limit spec passes here and fails on a copy carrying the previous simulation. The registered review gate (install, lint, type check, unit tests, format, build, browser and visual tests) passed on the reviewed tree, the tools suite's 1,116 tests among them, and CI's checks, visual and title jobs passed on the draft's head, whose tree is the reviewed tree. Known limits: a dictionary break such as Un-changed instead of Uncha-nged, one size for every heading of a header, headings aligned to the foot of the header and a fit by measured glyphs wait for the dedicated comparison pass over the states family; Data Mapper's bold Mapped and Unmapped headings cross their column rule by under a sixth of a pixel, as before; Service Layer's object note picks a draft's tab with a ternary that repeats the simulation's assignment; a states shape is typed by strings rather than the study's own unions. Browser checks ran in Chromium only.
