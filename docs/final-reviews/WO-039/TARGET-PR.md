# Reshape the enterprise pattern studies into the example to copy

The twenty enterprise application pattern studies landed with sixteen presentations that looked names up with `switch` statements carrying a `default` branch for a case the id union excludes, read token letters from nested ternaries, joined lists with their own helpers, typed on/off inputs as numbers, named transitions the shape already determined, ran comparison simulations inside the presentation and read the register drawing from their model specs. This change reshapes them so a colleague can open any enterprise presentation, say `gateway.presentation.ts`, read it top to bottom and copy what they read, with every frame, word and number on screen unchanged except the narrow register's state headings at a phone's width, which now stay readable. It also repairs Foreign Key Mapping's read limit, decides and documents the narrow headings' rule, writes the token rule down and moves the states drawing rule into a check of its own.

## What changed

The three commits can be read one at a time, and each passes the checks that cover it on its own export.

- **The narrow register.** At 360 pixels a state name wider than its column shrank until it fit, down to about six pixels for Service Layer's Announced. A heading is now drawn at the largest size at which its widest line fits its column, never below two thirds of the stylesheet's size; a word that would need less breaks across lines with a hyphen into the fewest parts that fit, the longer part first, and its lines take the size they then fit; a name with no words draws nothing. Six headings in three studies change: Service Layer's Accepted, Announced and Refused, Data Transfer Object's Encoded and Refused, and Record Set's Unchanged, their smallest headings rising from 6.16, 7.92 and 7.97 pixels to 9.24, 9.24 and 8.97. The other thirteen registers and the wide register are unchanged in every measured field. The register spec drives Service Layer's names at narrow columns and a register with empty names, the component spec checks that the template applies each column's scale in both layouts, a property test holds `breakWord` to the fewest parts that fit with no letter lost, and the catalog document states the rule.
- **The study check.** The rule that a states drawing of a model that runs reads that same module moves out of the RxJS checks into `statesProblems`, called beside `rxjsProblems`, with the rule, its message and its tooling test unchanged.
- **The reshape.** Each presentation reads a display name, a token letter and a state's or a part's name from a `Record` keyed by the study's id union and checked with `satisfies`, chooses by an operation's kind through `matchKind` in `studies/match-kind.ts`, a table of one function per kind, and keeps no `switch`: the sixteen held sixty-nine. Every list joins through `listOf`, an on/off input is a boolean read by `booleanParameter` in `studies/parameters.ts`, a comparison's two runs travel in the run description the entry module builds, Gateway's `isSuccessStatus` is the one 2xx rule and Service Stub imports it, and Record Set's positional transition helper goes. The states builder infers a move's transition where exactly one joins its states, takes none where none does, refuses an ambiguous move when the example builds and drops a null placement or note, each with a spec, so a snapshot names a transition only where the shape cannot tell it; `moveSentence` joins names through `listOf`; `registerOf` and the two `placeOf` return their state unions. A chart's x values sit under `seconds`, `steps` or `counts`, so a comparison over steps cannot pass for one over seconds, and the drawing reads them through `xValuesOf`. The tools test kit's `loadModelStudy(id, family)` replaces its two loaders and `tokensOf` reads token letters, so the thirty-seven flow and states specs import one loader and no model spec reads the register drawing. Foreign Key Mapping's loader stops on its read limit only before a key that needs a read, written once in `nextKeyOf`, so a limit of three finishes the identity-map run on three reads where it stopped short before; a spec pins every limit from one to six and the example keeps its limit of six and its run. The catalog documents state the lookup shape, the inferred transition, the one loader, the chart axes and the rule that a drawing's token letters are symbols shown through the house symbol template with the translated name beside them.

- Each commit passes on its own export: the first the tools library's type checks and the register, component and text specs; the second the tooling tests and the study check; the third the whole gate.

## Review

The final review read the whole diff and the verification's walkthrough, probes and controls, reproduced the shape audit and the grep counts, confirmed the working tree is the tree both gates and the draft's CI judged, read the narrow-register frames at 360 before and after the change, and made no source change beyond committing the reviewed tree as three commits. The draft had no review, comment or thread.

## Limits and follow-ups

None of these changes an output, and none blocks the change.

- A dictionary break such as Un-changed instead of Uncha-nged, one size for every heading of a header, headings aligned to the foot of the header, line spacing that scales with the drawn size and a fit by measured glyphs wait for the dedicated comparison pass that redraws the states family.
- Data Mapper's bold Mapped and Unmapped headings cross their column rule by under a sixth of a pixel in both builds, unchanged here.
- Service Layer's object note picks a draft's tab with a ternary that repeats the simulation's own assignment, and a states shape is typed by strings rather than the study's own unions; a stepped timeline over steps would label its scrubber in seconds, which only the component's comment rules out. The next standards pass over the batch takes them.
- Browser checks ran in Chromium only.
