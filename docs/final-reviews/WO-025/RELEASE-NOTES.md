## Release overview

`Launchpad v0.3.4` is a documents release. Every standing document of this launchpad was read as a whole under the kit's `quality pass:` procedure and brought to what is so, and the DotLn-Angular repository profile was rewritten to the shape the operator chose on 2026-10-30: a table of facts first, then task-named sections for what the repository is for, how to run it and its gate, where each house role is demonstrated, how a change is published, how a release closes, the versions and provenance, and the references. The operator record keeps every direction it had and carries ten standing directions no pass had recorded, each with its date and capture. The launchpad gains its own README at `docs/launchpad-readme.md`, off the root page while the starter's updates rewrite that one. The release is for the operator and for the sessions that read these documents at the start of their work. It is a patch release: no kit file or grant changes, and the kit is starter v0.103.1, taken by #41. Since `v0.3.3` the interval also merged eight starter updates (v0.93.0 to v0.103.1), ten planning passes and the review records of six DotLn-Angular orders (WO-006, WO-007, WO-013, WO-014, WO-019 and WO-015), each under its own pull request.
